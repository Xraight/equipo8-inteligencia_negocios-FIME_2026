## 🎯 Criterios de Storytelling Ejecutivo
- **Estructura Minto Pyramid:** Primero la conclusión y la respuesta de negocio; posteriormente los argumentos y datos de soporte.
- **Rigor Analítico:** Enfoque en la evidencia cuantitativa comprobada y honestidad respecto a las variables no observadas en el dataset.
