# Casa&Estilo — Ecosistema para el alumno
Sector: Muebles y decoración

## Escenario
Usted forma parte del equipo BI de Casa&Estilo. La dirección necesita una solución BI de principio a fin para comprender desempeño comercial, clientes, inventario/operación y rentabilidad.

## Entregables esperados
1. Perfilado y análisis de calidad de los archivos RAW.
2. Modelo ER operacional y propuesta de esquema estrella.
3. Staging en MySQL 8+ o PostgreSQL.
4. Pipeline ETL en SQL con bitácora de ejecución.
5. Data Mart analítico.
6. Dashboard en Excel 365 (Power Query + DAX) o Power BI.
7. KPIs estratégicos, tácticos y operacionales.
8. Storytelling: hallazgos y recomendaciones accionables.

## Reglas
- Los archivos RAW contienen problemas intencionales de calidad.
- No modifique los archivos fuente; limpie/estandarice en staging.
- Documente PK/FK, granularidad, reglas de negocio y transformaciones.
- Justifique cada KPI y visual.
- La solución debe ser reproducible desde SQL.
