# 01 - Modelo Dimensional Base (Unidad 2)

## 🎯 Objetivo General
Preservar y documentar el modelo dimensional conceptual, lógico y físico diseñado para **Casa&Estilo** como punto de partida indispensable para las consultas analíticas empresariales y optimizaciones de la Unidad 3.

## 📌 Función Específica
- Servir como referencia canónica para el esquema estrella del Data Mart de Ventas.
- Documentar las tablas de dimensiones (`Dim_Tiempo`, `Dim_Cliente`, `Dim_Producto`, `Dim_Showroom`, `Dim_Asesor`, `Dim_Canal`) y la tabla central de hechos (`Fact_Ventas`).
- Declarar el grano de la información y la resolución de las preguntas previas al desarrollo SQL.
